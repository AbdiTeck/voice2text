# voice2text
# 🎤 Voice2Text Web App

En fullstack webapplikasjon som lar brukere ta opp lyd i nettleseren og få automatisk transkribert tekst ved hjelp av OpenAI Whisper API.

---

## 🚀 Funksjoner

- 🎙️ Ta opp lyd direkte i nettleseren
- 🌍 Støtte for norsk tale (Whisper API)
- ⚡ Rask transkribering via backend (PHP)
- 💾 Lagrer transkripsjoner i database
- 🌐 Klar for deployment (Render + frontend hosting)

---

## 🧱 Teknologier brukt

**Frontend:**
- HTML
- CSS
- JavaScript (MediaRecorder API)

**Backend:**
- PHP
- MySQL

**API:**
- OpenAI Whisper (Speech-to-Text)
